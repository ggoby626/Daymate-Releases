# Daymate

Windows 일정·목표 관리 및 메이트 알림 앱의 공개 배포 전용 저장소입니다. 소스는 게시하지 않습니다.

## 다운로드

[최신 릴리스 다운로드](https://github.com/ggoby626/Daymate-Releases/releases/latest)

현재 **릴리스 1.0.1 / 내부 버전 60**입니다.
`Daymate-1.0.1-build60-windows.zip`을 받아 압축을 모두 풀고 EXE를 실행하세요. Windows 10/11 및 .NET Framework 4.8을 권장합니다.

**기존 1.0.0에는 업데이트 코드가 없어 최초 한 번 수동 교체가 필요합니다.** 이전 프로그램을 트레이 메뉴에서 종료한 뒤 새 EXE를 실행하세요. 기존 공개판 데이터는 그대로 사용합니다.

## 자동 업데이트

공개판은 실행 시 최신 정식 릴리스를 확인하고 다운로드·검증·교체·재시작합니다.
**내부 버전을 먼저 비교**하며, 같을 때 릴리스 버전을 비교합니다. 테스트판은 자동 업데이트하지 않으며 공개판과 분리됩니다.
`update.json`과 개별 EXE는 자동 업데이트용이며, 처음 다운로드할 때는 라이선스·사용 안내가 동봉된 ZIP을 권장합니다.

## 주요 기능

일정·일일/주간 목표, 자동 갱신, 수행 기록, 항목 순서 변경, 메이트 이름·이미지·대사, 물 마시기·스트레칭 알림, 음량 설정, Windows 자동 시작 및 트레이 실행을 지원합니다.

닫기(X)는 창을 숨깁니다. 완전히 끝내려면 트레이 메뉴의 **종료**를 선택하세요.
개인 데이터는 `%LOCALAPPDATA%\Daymate-Distribution`에 저장됩니다. 배포 파일에는 제작자 개인 데이터가 없습니다.
타사 출처와 라이선스는 ZIP 및 릴리스 첨부 파일을 참고하세요.
